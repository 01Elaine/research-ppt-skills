# 能力与范围

## 三种请求的最低可行交付

新论文制作需要可访问研究材料、PPT编辑能力和渲染能力。材料不足时先交有依据的提纲和缺口，未核验内容不能转成成果。测量论文不因版式有结果页就补算法实验。

局部修改需要读实际最终PPT。复制到独立目录后只改授权内容，比较受影响页与未授权部分。只改备注时，XML屏幕字节对照与相同工具的前后渲染可证明该工具下的屏幕一致；不能据此声称PowerPoint/WPS所有版本都等同。

只改文字/精简/融合默认保护统计图、架构图和保留截图。按图表清单比数量、类型、数据、关系、锁定几何及真实新文件的可见性；不能只看媒体关系或旧截图。另建公开占位资产不影响用户母版。

只读审查只需页面和口播可读，不能自动写回PPT。备注有解释时区分屏幕清晰度和口播补足，不以缺少独立挑战标题要求重复增页。

已有MD先读最新文件并保留用户措辞/删句；无PPT同步授权不批量写入，已明确授权则继续完成。按用户给定角色与唯一写入者协作，不强制固定session数量。新版保留旧PPT/PDF、脚本、素材和旧output，实际交付可编辑PPT及对应预览/所需PDF和准确入口。

听众、熟悉程度和总/局部时长由当前任务给出。第一目标是整篇连贯并讲懂，先主线/页目的和自然解释，再核实际锚点/必要英文定位，最后相近表达尽可能贴清楚顺口原话。页内讲序可调整而定位/转场清楚；真实图意、事实、口径、时长和图保护仍约束。制作指令放审校区，文本估时与真人演练分开。

## 客户端差异

本包不依赖某个Codex插件、个人模板目录、账号或远程服务。Codex可显式调用技能，其他工具可读取Markdown并按其规范工作。模板画廊识别属于客户端能力，未在本次验证；普通PPTX文件可单独打开使用。

某工具不能保留原生表格、备注或图表时，不能静默整页转截图。说明损失，在授权范围内选择能够保留这些对象的工具；缺少制作能力就交文本中间产物。渲染能力不足则写明视觉检查未完成。运行环境的机器路径不应写进公开技能。

## 公开与本地审查

当前16页公开占位模板只有自写文字、可编辑版式对象和显式示意数据。论文图表只留来源链接，使用者自己取得并确认使用范围。本地修正的SOC论文示例包含原研究图表，刻意留在公开包外，不因本地能打开而宣称已获再分发许可。
