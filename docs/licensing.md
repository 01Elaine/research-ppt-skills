# 许可范围

自0.1.0正式版起，01Elaine以MIT许可证发布本仓库中有权许可的原创技能规则、文档、脚本、讲述文本、占位文字及原创版式。正式全文见 [LICENSE](../LICENSE)，署名使用GitHub用户名，不包含汇报者真实姓名或单位。

## MIT覆盖的内容

- 两项技能的SKILL.md、UI配置、references与examples中的原创指导和讲述文字。
- tools下自写脚本，以及仓库文档。
- 两项技能的assets/blank-template.pptx及原RC7占位版式预览。
- 完整匿名参考中原创的文字、版式、原生表格和图示部分；与第三方图像混排的文件应结合下面的排除范围使用。

MIT允许按其条款使用、修改和分发上述原创部分，须保留版权声明和许可全文；MIT的免责条款保持原文。第三方声明是内容范围说明，不为MIT覆盖部分另加非商业等限制。

## 第三方素材单独排除

完整匿名参考PPT内的论文图表、论文表格截图、dblp网页截图、NCSA网页截图和其中的标识，不因放入本仓库而转为MIT。这些素材及其在预览中的对应内容仍归原权利人；没有在本次许可中授予它们新的权利。具体来源、嵌入路径和适用文件见 [THIRD_PARTY.md](../THIRD_PARTY.md) 与各技能的NOTICE.md。事实引用不等于图像再许可。

不能将包含第三方图片的整份参考PPT或其整页预览一揽子声明为MIT。需要仅使用MIT资产时，可选择空白占位模板，并自行提供或取得所需研究图片。论文作者、研究机构与学术出处继续保留；本轮没有加入论文PDF或字体文件。

## 独立安装

两个技能目录均附LICENSE与NOTICE.md；分发单独技能时保留这两份文件。asset-manifest.json与各references/reference-source.json分别标明MIT原创资产和混合第三方内容的参考资产。本次只正式确定许可及元数据，不改写参考PPT、图像或配对口播。

资产元数据中的 `LicenseRef-ThirdParty-Academic` 仅用于标识上述不由本仓库重新许可的第三方内容，不是新授予的许可证；`MIT AND LicenseRef-ThirdParty-Academic` 表示同一复合文件含MIT原创部分与第三方保留权利部分。
