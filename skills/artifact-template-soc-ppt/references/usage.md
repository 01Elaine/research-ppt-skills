# 完整结构与使用

| 页码 | 版式用途 |
| --- | --- |
| 1 | 封面：题名、论文作者/机构、汇报人和日期填写位 |
| 2 | 作者与团队：相关背景说明和两处公开来源截图位 |
| 3 | 目录：按主线导航，不逐项朗读 |
| 4 | 场景、概念与研究问题 |
| 5–6 | 总体方法、数据、定义与判定 |
| 7–12 | 案例、规模变化、分类来源、对象特征、原生证据表和并列证据 |
| 13–16 | 启示与建议、局限、方法论借鉴和结语 |

完整结构可选取或调整，不规定所有论文16页。表格横线、25%与8至1条形均为明确示意，不是实测数据。制作真实稿时补全来源，并同步数值与图形比例。两处作者页证据位是可编辑形状，未嵌入旧网页截图。

每页规划可记录：听众的问题、回答、必要证据与读法、前后页关系、结论边界、来源以及时间优先级。这些字段不需要展示给听众，也不要求机械对应固定段落。

任务级记录当前听众/熟悉程度、总时长与缓冲工作假设、局部目标、最新MD/PPT版本、授权范围及唯一写入者。面向初学者先解释场景与短术语，不堆长英文题名。目录一句导航，作者履历/导师关系/伦理资料备查；研究价值来自数据和研究工作。不固定任何分钟数、每页秒数或角色数量。

英文图的口播保留准确英文定位词，配中文含义和指图顺序，核对实际分支/反馈/输出关系。条件性例子：“先看左侧Inputs，也就是输入来源，再沿实际箭头到汇聚节点。”未读图时不能编英文标签或连线。制作指令和详细审校不进入口播，重要研究限定自然讲明。

连续通读仅口播区，检查术语是否前置、页界是否跳步/重复、分母是否突然变化、结尾是否回应开场，记录实际修复。来源区写证据和审校，不能把制作流程混进口播。必要研究限定仍须自然讲清。

整篇连贯与让听众讲懂第一：先全文主线及本页目的/前后衔接，再自然解释，随后核页面锚点与必要英文，最后内容相近处尽可能贴近清楚顺口的页面原话。事实、完整原意/子句、必要口径、实际时长和图表保护是约束，不为贴原话或压缩而破坏。

页内讲序允许为理解调整，不强制a/b/c或左右原排列；例如先右侧a的判定证据再回左侧定义，但定位和转换理由清楚。箭头/加号不逐字念，关系与术语保留；纸外解释关联证据且来源明确。顺口/对应/原意完整/主线清楚联合检查不能替代第一目标。将某次局部反馈升成最高规则、只逐块讲，是失败。

已有MD先读最新版本，保留用户手改/删句并按选段做最小修改；无同步授权不批量写PPT，已有直接制作授权则不增设确认。改后对照图表清单、对象类型/数据/关系、锁定几何和实际渲染。旧PPT/PDF、素材/脚本/旧output保留，交独立新可编辑版本和对应预览/所需PDF，给准确入口。按指定角色写入，其他角色只审查/验收。

参考色：白#FFFFFF，正文#1F2430，蓝#3E5C9A，解释#5A6472，来源#8A93A0，浅底#F3F5F8，边框#D8DDE3。中文微软雅黑，英文字体Times New Roman，均未随包分发。用户指定模板或字号优先；替代字体后重新渲染检查。
