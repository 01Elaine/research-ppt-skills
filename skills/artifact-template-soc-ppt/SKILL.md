# SOC 研究汇报 PPT

本技能附16页SOC完整匿名参考及对应原备注；仅清理汇报身份、报告日期和编辑元数据，保留学术来源与研究图表。参考文件只读；新汇报页数由材料与用户要求决定，不照搬16页，也不将旧论文数据当成新任务事实。

## 使用与讲述

1. 读取 [artifact-template.json](artifact-template.json)，相对于技能目录解析 [reference.pptx](assets/reference.pptx) 与 [preview.png](assets/preview.png)。先检查实际参考页面，再选择或复制需要的布局。复制到独立新目录后编辑，沿用母版、字体、图表、表格、数字模块和页脚层次，不替换为默认模板或整页截图。
2. 依据当前论文、实际最终PPT和最新讨论MD组织内容，复用已明确的听众、时长、授权及分工。具体工作和检查见 [usage.md](references/usage.md)，匿名参考来源见 [source.md](references/source.md)。使用能保留可编辑对象的工具；支持Codex Presentations时可沿用其模板流程，工具并非必需前置。
3. 第一目标是整篇连贯并让听众讲懂：先全文主线与本页目的及前后衔接，再自然解释，随后核对真实页面锚点和必要英文定位，最后在内容相近处尽可能贴近清楚顺口的PPT原话。事实、完整子句、统计口径、研究边界、任务时长与原图保护保持约束。
4. 先说做什么、为什么与实际问题，再讲整体方法、细节和证据。测量论文的具体RQ可承担挑战讲述，不机械增设挑战页或编造检测器。页内讲序允许为理解调整，定位与过渡清楚，不能改变图中关系。英文图保留关键真实英文标签及短中文解释；箭头和加号按关系转成自然句。
5. 每页备注分【口播稿】与【来源与审校记录，不口播】。制作指令、版本比较、详细审校不进入口播；影响结论的口径和限定自然讲清。连续审读全文，检查页间逻辑、图文对应及术语前置，估时与真人计时分开报告，不通过加快语速掩盖超时。

## 修改与交付

既有稿只改授权页或文字；只读审查不写回文件。原统计图、架构图和保留截图默认保护，优化文字、精简、融合不自动授权删除、替换、裁切或移入备份。锁定图的位置、尺寸、比例、裁切和图注按要求保留；明确例外按范围执行，不追加确认。

每次先读最新MD，保留用户措辞、删句与此前已确认内容；未授权同步时，MD更新不自动写入PPT。按指定角色和唯一写入者执行，Mentor被指定只审查时不编辑PPT。

保留旧PPT/PDF、脚本、素材及旧output，交独立新可编辑文件和对应预览/所需PDF。改前建图表清单，改后核对身份、对象类型、数据和关系、锁定几何及实际渲染可见性。不得只查文件关系存在或源码；缺少渲染或原生显示检查时明确实际范围，不声称已通过。

与参考逐页对应的原备注见 [reference-talk.md](examples/reference-talk.md)；新论文可从 [16页空白占位模板](assets/blank-template.pptx) 及 [通用口播](examples/template-talk.md) 开始。匿名参考含论文图表和公开网页截图，不将第三方素材并入MIT许可。使用者按自己的任务核对来源与使用范围。
