# SOC研究PPT可编辑版式库

独立可用的完整16页占位模板，包含封面、作者与团队、目录、研究问题、方法、证据、启示、局限、借鉴与结语。匹配当前模板的通用口播见 [template-talk.md](examples/template-talk.md)。个人身份、原论文图表与原口播不随包分发，新稿页数按任务决定。沿用白底蓝灰、标题层次、数字模块、线性条形、原生表格与逐图解释，保留内容丰富度。

沿用当前任务的听众、熟悉程度、总时长、局部目标、最新MD/PPT版本及角色，不固定分钟数或session数量。对入门听众先讲场景与逻辑，首次术语短解释，问题与整体方法先于细节。目录口播简述主线；作者履历、导师关系和伦理细节可备查。研究价值由真实工作与证据说明。

## 读取与使用

1. 读取 [artifact-template.json](artifact-template.json)，路径相对于本技能目录。模板为 [reference.pptx](assets/reference.pptx)，预览为 [preview.png](assets/preview.png)。先看实际页面再选需要的布局。
2. 将完整PPTX复制到新工作目录后修改。保留参考文件只读；按实际研究选择/复制页面，替换所有占位文字、示意数值和证据位。不能将预览整页贴入作为成品。
3. 先依据提供的论文组织研究问题、整体方法和证据，不为填版式编造结果。测量研究说明定义/标注/关联和统计；RQ已讲清困难时不重复增加挑战页。旧SOC场景或数据不是新稿事实。
4. 读 [usage.md](references/usage.md) 了解布局与讲述。可用任何能保留原生对象的PPT工具；支持Codex Presentations时可沿用其模板流程，插件不是前置条件。缺少制作/渲染能力时交文字规划并标明未完成的检查。
5. 每页备注区分【口播稿】与【来源与审校记录，不口播】。用自然口播解释证据为何支持回答，承接前页并引出后页，首次解释术语，overview先于细节。结果回到问题。连续读完整口播，不只逐页核词。
   英文图保留原图关键英文定位标签，配中文解释与空间/箭头顺序，不能只译中文或推断阶段与产出一一对应。研究限定自然讲清，制作/审校指令放非口播区。
   第一目标是整篇连贯并让听众讲懂：先全文主线和本页目的/前后衔接，再自然易懂的解释，随后核实际锚点/必要英文定位，最后内容相近处尽可能贴近清楚顺口的PPT原话。表述相近不倒置为最高规则。事实、完整子句、口径/边界、任务时长与原图保护保持约束。
   页内讲序已允许为理解调整，不强制a/b/c或左右原排列，但有真实定位与清楚过渡，不能改变图意。箭头/加号/标签转自然句，不逐字读符号；纸外解释关联证据并明确归属。先验全文讲懂，再逐段核顺口/对应/原意/主线，不能只查事实/XML。局部反馈按范围吸收，不升级成新的绝对最高规则。
6. 对实际最终PPT渲染检查断行、遮挡、图文对应和证据边界，保留表格/文字/条形可编辑。示意条形需连同数值和线性比例一起替换。估时说明语速和停顿依据，不声称未做的真人演练或UI检查。

用户已有PPT仅要求局部修改时，只改授权页和内容，保留其最终文件的版式及未授权部分；只读审查不写回文件。模板选择不扩大授权范围。

## 修改保护与交付

只改文字、精简口播、重设计外层版式或融合章节，都不自动授权删图、换图、裁切或移到备份。统计图、架构图和保留的网页截图默认保留；锁定对象的位置、尺寸、比例、裁切与图注原样。明确的放大/重排/删除例外按范围执行，不增设确认。空间不足先整理长文字、重复与审校说明，另建公开占位模板不能成为删改用户母版图表的理由。

已有讨论MD时每次先读最新文件，保留用户措辞、删句与口语习惯，只改指定范围；默认可先在MD讨论，已授权直接制作/同步则继续执行，未授权同步不能批量改PPT。按用户角色和唯一写入者分工，Mentor被指定只验收时不编辑PPT；不强制多session。

改前列图表清单，改后对照数量、对象类型、数据/关系、锁定几何及实际渲染可见性，不能只查媒体关系。保留旧PPT/PDF、脚本、素材和旧output，另存可编辑新版本及对应预览/所需PDF，准确指向新文件；work草稿或旧截图不算完成。总时长按本次参数安排，英文、数字、指图、停顿单独考虑，未演练不声称已计时，不靠加速解决超时。

## 公开候选边界

模板不含第三方论文图片、字体或个人元数据。证据位需要使用者自行提供合法素材。许可方案与来源说明在 [source.md](references/source.md)；当前是未安装、未公开上传的候选。画廊识别取决于客户端，不能把本地候选包称为已安装画廊模板。
