# 页级设计与口播规划

以下是工作记录字段，不是屏幕栏目或每页固定套话。页数、段落数和详略由材料决定，可合并不相关字段。

任务级先记录：听众/熟悉程度、评审关注、总时长及缓冲工作假设、指定页局部目标、最新MD/PPT版本、允许改的范围、锁定图表、写入角色与最终交付格式。复用当前已知信息，数字和角色不固定。

每页可补“保留图表身份/锁定项”“原图英文定位标签→中文解释→空间/箭头顺序”“用户手改保护项”。只记录实际材料，未知项标待核实；这些字段是规划，不自动进入屏幕或口播。

先记全文主线、本页目的和前后逻辑，再写自然解释；随后记实际锚点/必要英文定位与转场，最后列可贴近的清楚顺口页面表达。核心原意、不可丢子句/口径另外核验，不以逐字符相同或栏目原序为目标。

每个主段可记“目的 / 承接与引出 / 自然解释 / 实际锚点及转场 / 原意与口径 / 可贴近的原话”。页内讲序允许调整，记录为什么先右再回左等；不强制按a/b/c，讲序调整不授权改图。验收先整篇讲懂，再逐段对应与口读，局部建议不能替代统一目标。
