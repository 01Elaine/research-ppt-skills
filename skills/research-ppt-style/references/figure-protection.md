# 图表默认保护与可观察验收

## 修改范围先于布局判断

原统计图、论文架构图、原生图表/表格、组合图示及用户保留的网页截图默认保留。“优化文字”“精简口播”“重设计外层版式”或“融合章节”不是删图、换图、裁切或移到备份的授权。图仍在文件关系中，但被遮挡、挪出画布、隐藏、缩至不可读，也不算保留。

没有图表重排授权时保留原有图表区域，先改文字。用户明确允许放大/重排某图时按该范围执行，不重新请求已有授权；删除/替换按用户明确例外处理。用户指定锁定项时，位置、尺寸、比例、裁切、图注均原样保留。不能把笼统“做得更好”解释为这些例外。

空间不足依次整理重复读数、长段落、制作/审校说明，分组文字与解释，必要时在已授权范围内调整呈现。融合应保留原证据与讲述关系；无法满足全部约束时说明具体冲突并给可评审方案，不先悄悄删图或把图放到备份。

## 改前建清单，改后比实际输出

| 记录 | 改前与改后核验 |
| --- | --- |
| 图表身份/用途 | 页码、图号、标题或稳定身份；融合时给原图→新位置对应，不只比全稿总数 |
| 对象类型与内容 | 图片、原生图表、表格、组合形状；图片字节/哈希，图表数据、系列、单位，表格行列；不能静默转截图 |
| 关系与图意 | 源媒体/数据关联、图例、案例ID、分支/反馈箭头、标题图注；单有rId或关系不证明画面完整 |
| 锁定几何 | 指定对象的位置、尺寸、比例、裁切及图注逐项对照；仅有宽高比例相同不等于裁切未变 |
| 实际可见性 | 渲染最终新文件，检查遮挡、裁切、画布范围、可读性、层级和对应解释；图片存在但不可见视为失败 |
| 修改范围 | 只改文字时图表内容与锁定项相同；仅改备注时屏幕对象/渲染一致；未授权页保留 |

需要原生应用检查时记录实际执行范围，缺少该环境不能声称已验证。检查清单帮助找问题，不能替代实际渲染。保留旧版、媒体、脚本及旧output，报告实际新版本入口与未验证部分。

## 两个失败如何纠正

“三页融合，把两张统计图和一张架构图省去”是失败例子。正确做法是记录三图身份、全部保留并组织其证据关系；融合不要求删除图。

“作者页优化，只留左栏，省去右侧两张网页截图”也是失败例子。若右侧图被明确锁定，正确做法是只优化左栏文字、授权标题和口播，图的位置、尺寸、比例、裁切、图注逐项不变。

这两个案例不要求所有论文保留相同图或页数；默认保护对象由本次材料和用户要求决定，明确例外按授权执行。

## 公开素材治理是独立任务

另建不含未确认版权图像的公开占位示例时，保留用户母版原样。不要为了公开包许可而修改实际汇报中的图表。说明公开占位与研究汇报的区别，并分别给出资产/许可记录和修改范围证据。
